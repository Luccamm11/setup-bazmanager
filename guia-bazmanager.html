A Árvore de Habilidades é o coração do B-LEED. Cada tópico de conhecimento que você registra (ex: "Aprendi loops em Python") vira XP numa habilidade específica.
01
Adicionar Tópico de Conhecimento

03
Use a IA para Gerar Tópicos

Por que é importante? A Árvore alimenta o Dashboard de desempenho, a Jornada B-LEED exportável e garante que os técnicos saibam exatamente onde cada membro precisa de apoio.

Rastreio de Uso

Marque o item como "Em Uso" e informe onde está sendo utilizado (ex: "Robô principal"). Visível para toda a equipe.

01
Ao pegar um item
Encontre o item na lista → clique no círculo "Em Uso" → informe onde está sendo usado. Isso avisa toda a equipe.
02
Ao devolver o item
Clique no ✅ novamente para desmarcar "Em Uso". O item volta a aparecer como disponível para a equipe.
03
Adicionar item novo
Clique em "+ Adicionar Item" → preencha nome, categoria, quantidade e preço. Fica registrado no sistema para todos.

Planejamento

Planejamento 5W2H

Ferramenta de planejamento estruturado para qualquer projeto ou missão. Garante clareza, alinhamento e responsabilidade.

📋 Novo Plano
WHAT? O que será feito? (ex: Montar braço do robô)
WHY? Por que isso é necessário?
WHO? Quem será o responsável?
WHEN? Quando começa / termina?
WHERE? Onde será executado?
HOW? Como será realizado?
HOW $? Qual o custo estimado?
Enviar Plano para Revisão →
📐
O que é o 5W2H? Metodologia de planejamento com 7 perguntas fundamentais que garantem que um plano esteja completo antes de ser executado. Evita improvisação e retrabalho.
01
Criar um Plano
Clique em "+ Novo Plano" → preencha as 7 perguntas → envie para revisão dos técnicos.
02
Revisão pelos Técnicos
Jonas ou Ramon revisam o plano e aprovam ou pedem ajustes. Você é notificado sobre a decisão.
03
Executar com clareza
Com o plano aprovado, toda a equipe sabe exatamente o que, quem, quando, onde, por que, como e quanto custa.
⭐
Quando usar o 5W2H? Antes de qualquer projeto maior: subsistema novo do robô, evento de outreach, viagem para competição, compra de equipamento. Planejar é mais rápido que improvisar.
